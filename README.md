# 🚀 Universal No-Code HTML Designer

A lightweight, powerful desktop application built with **Python** and **PySide6** that empowers you to visually design, edit, and optimize HTML web pages and dashboards completely **offline**. 

No complex setups, no cloud subscription fees—just a fast, self-hosted layout designer tailored for developers, freelancers, and creators.

---

## ✨ Key Features

*   **🌳 Visual DOM Tree:** Navigate through your document structure easily. Drag-and-drop nodes to rearrange layouts instantly with real-time preview updates.
*   **👁️ Live Interactive Preview:** Powered by `QtWebEngine`. Click any element on the page to inspect and configure it immediately. Supports double-click inline text editing.
*   **💻 Embedded Monaco Editor:** Tweak raw HTML snippets of selected elements with a VS Code-like code editor environment.
*   **🎨 Visual CSS Control:** Easily adjust dimensions (Width/Height), padding, margins, display types, background colors, and text styles visually or via raw CSS code.
*   **📦 Component & Template Library:** Instantly insert responsive UI blocks (Grids, Cards, Tables, Headers, Footers, Contact Forms) and full pre-built pages or dashboards.
*   **🚀 Production Export Engine:** Automatically extracts messy inline CSS into a clean, optimized `style.min.css` file and bundles local assets into an `assets/` folder ready for deployment.
*   **⏪ Robust Undo/Redo System:** Full state tracking with `Ctrl+Z` / `Ctrl+Y` support.

---

## 🛠️ Tech Stack

*   **Core:** Python 3.x
*   **GUI & Web Engine:** PySide6 (Qt6)
*   **HTML Parsing & Manipulation:** BeautifulSoup4 (`bs4`), lxml
